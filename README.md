TextUtils – React Text Utility App

TextUtils is a simple React-based web application that helps users perform common text operations such as converting text to uppercase or lowercase, removing extra spaces, copying text, and clearing text. It also provides real-time word count, character count, and a live text preview. The UI is built using Bootstrap for a clean and responsive design.

🚀 Features

- Convert text to Uppercase and Lowercase

- Remove extra spaces

- Copy and Clear text

- Word count and Character count

- Live Text Preview

- Responsive UI using Bootstrap

🛠️ Tech Stack

◇ React

◇ Bootstrap

◇ JavaScript
